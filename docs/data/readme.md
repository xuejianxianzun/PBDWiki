# 对该目录的说明

这个 `data` 目录里保存着所有设置项和按钮的元数据。具体说明：

## 设置

`options_data.json`：对所有设置项进行分类。数组里的每一项代表一个设置项分类，每个分类里包含这些数据：
- `page`：该分类在这个 wiki 里的页面路径，里面区分了每种语言的路径。每个路径都可能有斜线 `/`，如果按照斜线分割的话，前面的路径都是文件夹的名字，最后一个斜线后面的路径是文件名。例如 `设置-抓取/抓取范围` 指向的文件是本项目里的 `/docs/zh-cn/设置-抓取/抓取范围.md`；`Settings-Crawl/Crawl-scope` 指向的文件是 `/docs/en/Settings-Crawl/Crawl-scope.md`。
- `ids`：保存了该分类里所有设置项的 id。在设置项的 html 代码里，会使用 id 作为 `data-no` 属性，如 `data-no="0"`。
- `names`：保存了该分类里每个设置项的名字，用 id 区分。这是显示在网页上给用户看的。`name[zh-cn]` 保存的是它在简体中文里的名字，`name[en]` 保存的是它在英语里的名字。

## 按钮

`buttons_data.json`：对所有按钮进行分类。数组里的每一项代表一个 Pixiv 里的页面类型，因为下载器是按照页面类型来对按钮进行分类的。不过有些按钮会出现在多种页面里，所以有时我会使用“通用”分类（它不代表某个具体的页面类型）。

每个分类里包含这些数据：
- `page`：该分类在这个 wiki 里的页面路径，里面区分了每种语言的路径。含义与“设置”里的 `page` 含义相同。
- `ids`：保存了该分类里所有按钮的 id。它们会作为按钮（`button` 元素）的 id 属性。
- `names`：保存了该分类里每个按钮的名字（就是按钮上显示的文字），用 id 区分。这是显示在网页上给用户看的。`name[zh-cn]` 保存的是它在简体中文里的名字，`name[en]` 保存的是它在英语里的名字。
