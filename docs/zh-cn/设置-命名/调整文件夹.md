启用此设置后，符合条件的文件不会创建文件夹，而是直接保存到浏览器的下载目录里。

子选项：

- 从插画、漫画里下载 1 张图片时：如果你只从这个作品里下载了 1 张图片，就不为这张图片创建文件夹。每个作品都会单独计算。

- 从插画、漫画里下载多张图片时：如果你从这个作品里下载了多张图片，就不为这些图片创建文件夹。每个作品都会单独计算。

- 动图：不为动图作品创建文件夹。

- 小说：不为单篇小说作品创建文件夹。

提示：

如果你启用了所有子选项，那么所有作品都不会创建文件夹。

此设置不适用于合并系列小说后生成的合集文件。如果你想让合集文件不创建文件夹，可以在“命名 / 文件夹和文件的名字”里修改“合并系列小说时的命名规则”。

下载器可以为多图作品添加一层单独的文件夹。在下载器面板上点击该设置的“帮助”按钮可以查看详细说明。

例如以作品 [79239641](https://www.pixiv.net/artworks/79239641 ':target=_blank') 有 3 张图片，启用此功能可以把图片放进以作品 ID 命名的目录里，如下：

```
79239641/
  |---- 79239641_p0.jpg
  |---- 79239641_p1.jpg
  |---- 79239641_p2.jpg
```

**子选项：**

- `当作品里的图片数量超过指定数量时启用`：当这个作品里的图片数量大于设置值时，下载器才会为其添加这里设置的文件夹。默认是 1，会对所有多图作品生效。你也可以设置为其他值。
- `要添加的这层文件夹的规则`：为多图作品添加的文件夹的名称。你可以像设置命名规则一样使用各种标记和自定义文字，也可以使用 `/` 来建立文件夹。默认值是 `{pid}`，也就是使用作品 ID（不带序号）建立文件夹，把文件存放在里面。

之后你还需要修改“图像作品的命名规则”设置，在你需要的地方插入 `/{multi_image_folder}/` 来添加一层文件夹。示例：`pixiv/{user}-{user_id}/{multi_image_folder}/{id}-{title}`

之所以需要手动插入这个标记，是为了让用户可以自行决定这层文件夹的位置。虽然通常它会添加到文件名前面，但有些用户可能需要把它放到其他位置，例如更上层的文件夹，或者文件名里。

**提示：**

- 如果你要在文件夹名字里使用作品 ID，那么不应该使用 `{id}` 标记，而是应该使用 `{pid}`。因为多图作品里的每张图片的 `{id}` 都不同，如果使用 `{id}` 会导致每个图片都会建立一个文件夹。
- 虽然设置名字写着“添加一层文件夹”，但你其实可以在这里设置多层文件夹。
- `{multi_image_folder}` 本身不会创建文件夹（除非你设置的文件夹规则里已经以斜线 `/` 结尾），所以需要在它后面添加斜线 `/` 来建立文件夹。不过有时这也是个可以利用的特性：如果你不想建立文件夹，而是想在文件名里把它标注为多图作品，就可以利用这个特性。例如我把文件夹规则设置为 `多图`，并把它添加到文件名里：`pixiv/{user}-{user_id}/{id}-{multi_image_folder}`，那么文件名里就会有“多图”标记：`pixiv/はまけん-3779820/144008705_p0-多图.jpg`

使用方法：

如果你想在作品里含有特定标签时建立一层特殊文件夹，可以启用这个设置。

例如：作品 [94964157](https://www.pixiv.net/artworks/94964157 ':target=_blank') 含有“原创”标签：

![](../../template/zh-cn/images/20250910_224847.png)

如果你在这个设置里输入了 `原创`，下载器就会建立“原创”文件夹存放这个作品：

![](../../template/zh-cn/images/20250910_224705.png)

**使用方法：**

首先在这个设置里输入目标标签，如果有多个标签，使用英文逗号 `,` 分割。注意：在这里只需要输入目标标签，不要填写完整的命名规则。

你可以设置 2 个标签列表：`{match_tag_folder1}` 和 `{match_tag_folder2}`。这是为了处理一个常见的需求：如果一个角色属于某个作品，就建立两层文件夹：第一层是作品名字，第二层是角色名字。例如我在 `{match_tag_folder1}` 里设置作品名字 `GenshinImpact`，并在 `{match_tag_folder2}` 里设置角色名字 `フリーナ`。如果一个作品同时含有这两个标签，下载器就可以为这个作品添加两层文件夹：`GenshinImpact/フリーナ/`。

当然，如果你没有这个需求的话，可以只使用第一个标签列表。

在你设置标签列表之后，还需要修改“命名 / 文件夹和文件的名字”里的“命名规则”设置，在需要的地方插入特定标记和斜线来添加一层文件夹。`/{match_tag_folder1}/` 代表第一个标签列表的匹配结果，`/{match_tag_folder2}/` 代表第二个标签列表的匹配结果。

示例：`pixiv/{match_tag_folder1}/{match_tag_folder2}/{id}`

**匹配方式：**

下载器会在作品的标签列表里查找你设置的标签，并且会优先使用标签别名。

匹配模式是完全一致，不区分大小写。如果你设置了 `A`，可以匹配到 `a` 或者 `A`，但不会匹配到 `abc`。

对于你设置的每个标签列表，下载器都会按顺序查找：先查找你设置的第一个标签，如果找不到就查找第二个，以此类推。一旦找到第一个匹配的标签，就停止查找，并用它替换命名规则中的对应标记：`{match_tag_folder1}` 或 `{match_tag_folder2}`。

如果没有匹配到你设置的标签，下载器会忽略对应的标记。

使用这个设置，你可以对含有特定标签的文件进行单独的分类。

**使用标签别名来统一文件夹名字：**

有些标签有多种变体，例如 `GenshinImpact` 有这些变体：`GenshinImpact,Genshin Impact,Genshin,原神,原神インパクト`。如果你想把这些标签都视为 `GenshinImpact`，并且只建立 `GenshinImpact` 文件夹（而不是使用变体来建立多个不同的文件夹），就可以使用该设置下方的“标签别名”功能。

把这些变体的别名设置为 `GenshinImpact`，然后在这个设置里只需要使用 `GenshinImpact` 即可匹配到所有变体。

当你在你的收藏页面里抓取作品时，如果想使用某些收藏标签（而不是作品本身的标签）来建立文件夹，就可以使用这个设置。

先填写你想设置为文件夹名字的标签，然后修改命名规则，添加特殊标记来建立文件夹。例如：

`pixiv/{match_bookmark_tag_folder1}/{match_bookmark_tag_folder2}/{id}`

原理：

这个设置会检查你为已收藏的作品添加的标签（可能是你设置的自定义标签）。如果作品的收藏标签与你在这里设置的某个标签相同，下载器就可以输出这个标签，用于文件夹或文件名里。

使用方法：

可以参考“使用第一个匹配的标签建立文件夹”设置的帮助内容，两者的使用方法非常相似。区别在于：

- 这个设置使用 `{match_bookmark_tag_folder1}` 和 `{match_bookmark_tag_folder2}` 标记输出匹配结果。

- 这个设置在匹配标签时，使用的是你为已收藏的作品添加的自定义标签（`{bookmark_tags}`），而不是作品本身的标签（`{tags_translate}`）。

- 只有当你在自己的收藏页面里抓取时，这个设置才会生效。这是因为在收藏页面里，下载器可以获取到你为作品添加的收藏标签；但是在其他页面里，下载器获取不到你设置的收藏标签，所以这个设置无效（不会建立文件夹）。
