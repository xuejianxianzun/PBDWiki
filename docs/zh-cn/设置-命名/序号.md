你可以设置图片的序号从 `0` 开始还是从 `1` 开始。

下载器默认会从 `0` 开始，因为 Pixiv 图片的文件名就是从 `p0` 开始的。如果你想改为从 `1` 开始，可以修改此设置。

这个设置会影响含有序号的命名标记：`{id}`、`{p}`。

**注意：**如果你把序号设置为从 `1` 开始，并且启用了“不下载重复文件”功能，那么需要注意：对同一个文件，之前的下载记录里保存的序号是 `0`，当以后再次下载时，由于新的文件名里序号是 `1`，会导致文件名不同，所以“严格”策略会再次下载这个文件。使用“宽松”策略则不会再次下载它。

什么是序号？如果你使用 `{id}` 命名，每个作品的 id 后面都会带序号，如：

```
80447108_p0
80447108_p1
80447108_p2
```

结尾的 `_p0`、`_p1`、`_p2` 就是序号。

如果你启用了这个选项，下载器会去掉**每个作品的第一张图片**的序号，变成这样：

```
// 第一张图片去掉了序号 0
80447108
80447108_p1
80447108_p2
```

**子选项：**
- `单图作品`：为单图作品去掉序号。
- `多图作品`：为多图作品的第一张图片去掉序号。
- `动图`：为动图作品去掉序号。

?> 命名标记 `{p}` 也会输出序号，它输出的是纯数字的 `0`、`1`、`2`。这个设置对 `{p}` 也会生效，即可以去掉 `{p}` 输出的 `0`。

插画和漫画作品因为可能有多张图片，所以文件名里是有序号的。例如：

```
0
1
2
3
...
10
11
12
...
```

下载器默认不会在序号前添加 0，但是一些软件对于文件名排序不正确，在这种情况下需要添加 0。

**注意：**如果你没有遇到“按文件名排序时，因为序号而导致排序不正确”的问题，就不需要启用这个设置。

此问题经常出现在 Android 系统上，很多文件管理器可能会把文件错误的排序，像是这样：


```
0
1
11
12
...
2
20
21
...
3
30
...
```

原因是这些文件管理器把文件名作为字符串进行排序，所以导致了这个问题。

此时你可以启用这个功能，下载器会在序号前面填充 0：

```
001
002
003
...
010
011
012
...
```

这样就解决了排序错误的问题。

你可以在子选项里设置填充后的序号长度，默认为 3。

?> pixiv 的单个插画或漫画作品最多可以有 200 张图片，所以把长度设置为 3 是最合适的。
