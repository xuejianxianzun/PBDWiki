下载器把动图保存为多种格式，你可以根据需要选择一种或多种格式。

点击该设置右侧的”帮助“按钮可以查看详细说明。

**提示：**
- 默认的格式是 WebP 图片（有损）。
- 把动图保存为 ZIP、Ugoria 格式时不需要转换，所以速度很快。其他格式都需要转换。
- 转换动图格式需要一些时间，可能会花费几秒钟到几分钟，这取决于动图的原始分辨率、体积，以及转换的目标格式。
- 转换动图时，下载器的进度条可能不会变化，这是正常的，因为下载器在等待动图转换完成。
- Firefox 生成的 WebM 视频体积比 Chrome 生成的 WebM 视频体积小，平均体积约为后者的 40%，码率也更低。这是因为两个浏览器内部的 VideoEncoder 不同导致的。

## 同时转换多少个动图

  <a href="http://localhost:3000/#/zh-cn/设置-下载/动图?flag=66" target="_blank" class="has_tip settingNameStyle" data-xztip="_同时转换多少个动图的说明" data-tip="同时转换多个动图会增加资源占用。&lt;br&gt;
    建议不超过3。" data-bind-click="true">
    <span data-xztext="_同时转换多少个动图">同时<span class="key">转换</span>多少个动图</span>
    <span class="gray1"> ? </span>
  </a>
  <input type="text" name="convertUgoiraThread" class="setinput_style blue" value="1">
</div>

默认值是 `1`。

**提示：**

- 下载器在转换动图时会使用较多的 CPU 和内存资源。
- 同时转换多个动图会增加资源使用量。如果一个页面的内存使用量太多，可能会导致页面崩溃，所以这个值不应该设置的太大。建议不超过 `3`。
- 动图的同时转换数量不会超过同时下载数量。如果下载器同时下载 3 个文件，那么同时最多也只会转换 3 个动图。
