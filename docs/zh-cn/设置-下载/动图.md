下载器可以把动图保存为多种格式，并且你可以根据需要同时选择多种格式。

**格式列表：**

- WebP 图片：可以选择有损或无损压缩。相比其他图像格式，在画质相同时的体积最小，推荐使用。

- WebM 视频：有损压缩。它是视频文件，需要使用视频播放器打开。

- GIF 图片：有损压缩。优点是兼容性好，缺点是画质最差，体积也比较大，不推荐。

- APNG 图片：无损压缩。缺点是体积最大，而且转换耗时也最长。

- ZIP 文件：无损。它是动图的源文件，包含多张静态图片，并且下载器会在里面添加一个 JSON 文件保存动画的元数据。

- Ugoira 文件：无损。它其实就是 ZIP 文件，只是扩展名为 .ugoira。

**子选项：**

- WebP 图像质量：你可以设置 WebP 图片的质量，默认是高质量的有损压缩。你也可以改为无损压缩。

- 为动图保存一张缩略图：下载动图时，保存一张它的静态缩略图文件。

**推荐的格式：**

我推荐优先使用 WebP 图片，因为它在相同画质时的体积最小。缺点是一些比较旧的看图软件可能不支持查看 WebP 动图。

另外，对于 Windows 用户我也很推荐使用 Ugoira 文件。你可以安装 [BandiView](https://www.bandisoft.com/bandiview/) 来播放 .ugoira 文件（免费版即可），此时 Ugoira 文件有很多优点：原始文件，无损，有动画效果，无须转换，体积也小。但是其他系统可能没有类似的软件。

**每种格式的体积：**

我下载了近期的 1000 个动图作品进行测试，下面是每种格式的平均体积，仅供参考：

- ZIP/Ugoira：9MB

- WebP：7 MB（有损压缩）或 35 MB（无损压缩）

- WebM：10 MB

- GIF：20 MB

- APNG：48 MB

从小到大排序：WebP（有损）< ZIP/Ugoira < WebM < GIF < WebP（无损）< APNG。

**在资源管理器里显示缩略图：**

这部分说明只适用于 Windows 系统。通过一些设置，你可以在资源管理器里查看所有动图格式的缩略图。

- GIF 图片：系统本身就支持显示它的缩略图。

- WebP 图片：安装 [BandiView](https://www.bandisoft.com/bandiview/)，然后按 F5 打开它的设置，在“快捷菜单”设置的“缩略图预览”里选择 WebP 格式，即可显示 WebP 动画的缩略图。

- WebM 视频：安装 [K-Lite Codec Pack](https://www.codecguide.com/download_k-lite_codec_pack_standard.htm) 即可显示 WebM 视频的缩略图。

- APNG 图片、ZIP 文件、Ugoira 文件：在 Icaros 里添加这些格式的扩展名，就可以显示它们的缩略图。如果你安装了 K-Lite Codec Pack，那么它应该自带了 Icaros，你可以在开始菜单里搜索来找到它。如果你找不到它，也可以单独安装 [Icaros](https://github.com/Xanashi/Icaros/releases)。运行 Icaros，启用它的缩略图功能，在文件类型列表的末尾添加 `;apng;zip;ugoira`，或者把对应类型的文件拖拽到 Icaros 的窗口里来添加它。

**提示：**

- 默认的格式是 WebP 图片（有损）。

- 把动图保存为 ZIP、Ugoira 格式时不需要转换，所以速度很快。其他格式都需要转换。

- 转换动图格式需要一些时间，可能会花费几秒钟到几分钟，这取决于动图的原始分辨率、体积，以及转换的目标格式。

- 转换动图时，下载器的进度条可能不会变化，这是正常的，因为下载器在等待动图转换完成。

- Firefox 生成的 WebM 视频体积比 Chrome 生成的 WebM 视频体积小，平均体积约为后者的 40%，码率也更低。这是因为两个浏览器内部的 VideoEncoder 不同导致的。

默认值是 `1`。

**提示：**

- 下载器在转换动图时会使用较多的 CPU 和内存资源。
- 同时转换多个动图会增加资源使用量。如果一个页面的内存使用量太多，可能会导致页面崩溃，所以这个值不应该设置的太大。建议不超过 `3`。
- 动图的同时转换数量不会超过同时下载数量。如果下载器同时下载 3 个文件，那么同时最多也只会转换 3 个动图。
