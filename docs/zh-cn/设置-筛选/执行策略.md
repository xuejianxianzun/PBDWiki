## 不抓取下载过的作品

<div class="option settingsPanel_optionCard" data-no="26" data-pin-bound="true" style="display: flex;">
  <a href="/#/zh-cn/设置-筛选/执行策略?flag=26" target="_blank" class="settingNameStyle" data-bind-click="true">
    <span data-xztext="_不抓取下载过的作品">不抓取<span class="key">下载过</span>的作品</span>
  </a>
  <input type="checkbox" name="DonotCrawlAlreadyDownloadedWorks" class="need_beautify checkbox_switch">
  <span class="beautify_switch" tabindex="0"></span>
</div>

如果你启用了该功能，那么下载器在抓取每个作品前会先检查它是否有下载记录，如果有就不抓取它。这样可以减少不必要的抓取，节约时间。这个功能也有助于增量更新，因为你可以只抓取没有下载过的作品。

另外，在合并系列小说时，启用该设置可以跳过有下载记录的小说，只合并系列里新增的小说。

**注意：** 
- 该功能依赖下载器保存的下载记录，所以不是完全准确的。如果你清除了下载器的下载记录，那么下载器会忘记它下载过哪些文件。如果你想详细了解下载器的下载记录，可以查看 [管理下载记录](/zh-cn/设置-下载/下载记录?id=管理下载记录) 里的说明。
- 以前下载器在合并系列小说时不会保存每篇小说的下载记录，所以它们可能依然会被下载一次，之后就可以不再重复下载了。
- 对于多图作品，只要你下载过其中一张图片，这个作品就会被视为已下载，以后抓取时会跳过它。

你可以输入想要屏蔽的用户的 ID，这样下载器就不会下载这些用户的作品。

?>注意：需要输入**用户 ID**（数字），而不是用户名。因为用户名不唯一，并且可能会变化。

?>如果要屏蔽多个用户，可以输入多个用户 id，中间使用英文逗号 `,` 分割。

**子选项：**

### 快捷屏蔽用户

当你把鼠标指针停留在任意用户的名字上时，下载器会显示一个屏蔽按钮，点击按钮即可屏蔽这个用户。

### 从页面上移除他们的作品

启用之后，下载器会在多种页面上查找被屏蔽的用户的作品，如果有就移除它们，这样你就不会看到不喜欢的用户的作品了。

当下载器移除了某些用户的作品时，会在顶部日志里显示详情，例如：

<span style="color: rgb(210, 126, 0);" class="log">移除了用户 <a href="https://www.pixiv.net/users/6756759" target="blank">村上水軍</a> 的作品<br></span>

?>在被阻止的用户的主页里不会移除他们的作品，以便让用户可以正常查看他们的主页。

减慢抓取速度可以避免下载器在抓取时被 Pixiv 临时限制（查看 [什么是 429 错误](/zh-cn/常见问题?id=什么是-429-错误)），但是会增加抓取时间。

如果用户启用了这个设置，那么下载器在抓取时的并发请求数量会变成 1。在每个请求完成之后，等待一定时间（取决于间隔时间的值）再发送下一个请求，以降低抓取频率，避免触发 429 限制。

这个设置有 2 个子选项：

### 当作品数量超过指定数量时启用

当要抓取的作品数量超过这个数字时（默认是 `100`），下载器才会使用慢速抓取模式。

如果要抓取的作品数量小于这个数字，下载器就会快速抓取（没有间隔时间）。

### 间隔时间

当一个请求完成后，等待多长时间再发送下一个请求。单位是毫秒，默认值是 `1600`。

如果你每天只抓取几百个作品，默认的间隔时间通常是安全的。如果你经常触发 429 错误，或者经常抓取更多作品，可以增加间隔时间，例如 `2000`、`3000`。`4000` ms 几乎是绝对安全的，即使抓取超过一万个作品也没问题，但通常不需要使用这么大的间隔时间。

?> 间隔时间不仅会在抓取阶段生效，也会在需要发送大量请求的一些场景里生效。例如：批量添加收藏、获取关注的用户列表。

------------

**注意：**

这个设置并不能完全避免 429 错误。原因：

1. 它假设用户只在一个页面抓取，此时应该不会触发 429 错误。但如果用户在 2 个或 3 个页面里同时抓取，因为发送请求比较频繁，就依然可能会触发 429 错误。
2. 用户的一些正常操作也是会消耗额度的，例如打开作品页面、预览作品、收藏作品等，当额度用尽时就会触发 429 错误。所以在抓取时，如果用户进行了很多此类操作，也可能会导致触发 429 错误。

这个功能是为了提供所见即所得的体验。你可以预览抓取结果，并且可以对抓取结果进行筛选，最后再下载。

**调整抓取结果：**

- 清除多图作品、清除动图作品、手动排除作品

**每页显示的作品数量**：

当抓取结果较多时，下载器会分页显示，以降低性能压力。

**子选项：**

- **当抓取结果大于指定数量时启用**：如果你只想在有较多抓取结果时导出，可以使用这个设置。当抓取结果的数量大于指定值时，才会导出抓取结果。备注：如果设置为 0，那么只要有一条抓取结果就会导出。

## 获取作品 ID 列表后导出 ID 列表，并停止任务

<div class="option settingsPanel_optionCard" data-no="31" data-pin-bound="true" style="display: flex;">
  <a href="/#/zh-cn/设置-筛选/执行策略?flag=31" target="_blank" class="settingNameStyle" data-bind-click="true">
    <span data-xztext="_导出ID列表">获取作品 ID 列表后导出 <span class="key">ID 列表</span>，并停止任务</span>
  </a>
  <input type="checkbox" name="exportIDList" class="need_beautify checkbox_switch">
  <span class="beautify_switch" tabindex="0"></span>
</div>

如果你想获取下载器抓取到的作品 ID 列表，并且不需要下载文件，就可以启用这个选项。

**导出时机：**

- 导出时机是在下载器获取了所有要抓取的作品 ID 之后。注意这不是“抓取完成后”，而是更早。

下载器的抓取阶段分为 2 个步骤：
1. 获取所有作品的 ID 列表。
2. 逐个获取作品的详细数据，检查过滤条件，保存符合条件的作品的数据。

导出时机是在步骤 1 之后，并且会停止任务，也就是不会执行步骤 2。

!> 由于导出时机比较早，此时没有应用过滤器，所以导出的作品 ID 里可能含有不符合过滤条件的作品。

**导出的内容：**

导出的作品 ID 列表会保存到一个 JSON 文件里。你可以自行处理该文件，不过从设计目的上，这是为了配合另一个功能使用的：首页的 [导入作品 ID 列表](/zh-cn/按钮-开始抓取/首页?id=导入作品-id-列表)按钮。

**使用示例：**

当你需要抓取的作品来自多个不同页面，而你想把它们汇总为一次抓取任务时，可以这样做：

- 启用此设置；
- 获取每个页面里的作品 ID 列表；
- 汇总到一起（将所有作品 ID 放在同一个 JSON 文件中）；
- 关闭此设置；
- 使用首页的“导入 ID 列表”功能开始抓取。
