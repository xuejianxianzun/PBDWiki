## Import ID list

<button id="importIDList" type="button" class="hasRippleAnimation settingsPanelActionBtn" data-btn-emphasis="secondary" data-btn-intent="brand"><span data-xztext="_导入ID列表">Import ID list</span><span class="ripple"></span></button>



Clicking this button allows you to select a JSON file containing a list of work IDs for the downloader to crawl.

The JSON file format is as follows:

```json
[
  { "id": "142565679", "type": "illusts" },
  { "id": "24769308", "type": "novels" },
  { "id": "7671451", "type": "novelSeries" }
]
```

`id` is the work ID, and `type` is the work type, which can be `illusts`, `novels`, or `novelSeries`.

?> This JSON file can be generated by the [After obtaining the work ID list, export the ID list and stop the task](/en/Settings-Crawl/Execution-strategy?id=after-obtaining-the-work-id-list-export-the-id-list-and-stop-the-task) function. These two functions are designed to work together. However, you can also create your own ID list as long as the format meets the requirements.
